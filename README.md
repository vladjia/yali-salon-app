# 雅麗｜預約管理

媽媽專用前端，資料由 GAS 管理。公開程式不含管理金鑰、客人資料或預約資料。

- `index.html`：核定管理畫面，改為 fetch 呼叫 GAS。
- `connection.js`：讀取網址片段 `#k=` 或裝置儲存的金鑰；POST 不加自訂 headers。
- `poster.html`：核定 420 × 600 mm 海報 v3，公開服務資料。
- `連線測試.html`：只測連線、14 天列表及版本，不送單、不顯示客人內容。
- `manifest.webmanifest`：加入主畫面。暫不設 start_url，保留原啟動網址片段。

價格編輯使用同網站 price.html，內嵌於管理App，返回時關閉內嵌頁；資料仍由GAS處理。未加 service worker、離線資料快取或推播。
手機加入主畫面後，須實測關閉再開啟；不要分享媽媽的完整專用網址。

前端維護：景序；GS 後端與總檔案管理：慎言；需求與實機驗收：元家。
